# Multi-Platform Social Media Advertisement & Revenue Analytics Platform

## Overview
A full-stack Data Analytics Platform that simulates how companies analyze 
advertisement performance across Instagram, Facebook, YouTube, LinkedIn, 
and WhatsApp.

## Tech Stack
| Layer | Technology |
|-------|-----------|
| Language | Python |
| Database | PostgreSQL |
| Backend | FastAPI |
| Data Processing | Pandas |
| Visualization | Power BI |
| Containerization | Docker |
| Version Control | Git/GitHub |
